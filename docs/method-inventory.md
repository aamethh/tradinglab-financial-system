# AmethQuant Method Inventory

**Fuente oficial:** código fuente de https://amethquant.vercel.app (este repo, carpeta `web/src/`).
La web en vivo devuelve HTTP 403 a fetchers automatizados, pero el código desplegado es este repositorio
(verificado vía historial de commits y `vercel.json`), por lo que todo lo listado aquí es literal y verificable.

**Regla:** todo lo que está en la sección 1 aparece textualmente en la web. Lo que no aparece en la web
está en la sección 2 ("Proposed Additions") y NO es metodología oficial hasta que Ameth lo apruebe.
